# Production plan

Build a Godot 4.6.3 Compatibility project targeting the single-thread Web export. Start with the existing original rig and native code patterns, then build the city and encounter systems in the engine. The Godot project is independent of the earlier hosted renderer. Use official matching templates and a local browser run as the Web compatibility gate.

Run Godot headless editor import at integration points. Use small headless scene and data harnesses, then high-value scripted runs and a clean release export browser test. Keep shaders and effects scalable in Compatibility. Track scope in CHECKPOINTS.md. Physical tablet results require hardware access. Preserve any unresolved release blockers in QA_REPORT.md.
